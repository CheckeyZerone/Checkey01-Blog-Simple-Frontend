设计稿在 `checkey01-blog-web-design` 文件夹（本仓库外；跨电脑时以实际路径为准）：

- Logo：`blog-logo-text.svg`（V1 字标，已复制到本仓库 `public/`）

## 四条总原则

1. **数据与页面解耦**：文章、相册、友链、关于我各自独立成数据文件 + 类型接口，页面只从统一入口取数。后期后端就绪后只换数据源实现（沿用 T7 的 local-source / remote-source 模式），页面不动。
2. **每步完成必过审查关卡**：按 `tasks/README.md` 通用审查清单验收（type-check / lint / build / 目测 / 死链 / 垃圾清理 / 复用性），发现问题当场修复，不留屎山。
3. **旧标签页彻底改造**：不做新旧两套页面。标签页直接改造成文章列表页，旧路由删除或只留重定向壳。
4. **相册后置，复用性前置**：相册页 / 图片内容页 / 相册检索最后实现，但 AlbumCard、分页组件、标签筛选条等公共件前期先设计好，被首页 / 文章页先用，相册阶段只是组合复用。
