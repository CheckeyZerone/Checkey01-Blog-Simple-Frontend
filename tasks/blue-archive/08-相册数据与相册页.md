# T-D8 相册数据与相册页

**目标**：完善相册数据模型，完成相册页（标签筛选 + 图片网格 + 分页），图片暂时用渐变色块占位。

## 涉及文件

- `src/data/albums.ts`（数据模型 + 示例数据）
- `src/components/AlbumCard.vue`（按最终设计完成，替代空壳）
- 新建 `src/views/AlbumsView.vue` + 路由 `/albums`
- 复用 `Pagination.vue`、`TagFilterBar.vue`

## 步骤

1. 数据模型（字段与后端可对齐）：
   - 相册 `Album`：`slug / title / category / date / photos`
   - 照片 `Photo`：`id / title / tags / date / description / image`
   - image 先用渐变色块标识或空字符串，真实图片后续替换
2. AlbumCard：整图圆角卡片 + 底部渐变遮罩 + 相册名 / 照片数图注；高度约 200px（窄屏 208px），与文章卡片对齐
3. AlbumsView：筛选条（全部 / VRChat / 题解 / 生活 / 服务器 + 数量）→ 三列 → 两列 → 单列网格 → 分页
4. 示例分区三条：VRChat 日常（12 张）/ 题解截图（8 张）/ 生活随手拍（23 张）
5. 首页「最新相册」若此前未做，现在接入（复用同款 AlbumCard）

**完成标志**：`/albums` 与设计稿一致，筛选、分页、移动端正常；首页最新相册正常。

**审查重点**：AlbumCard 不写死数据（props 接收）；照片数从 `photos.length` 计算；占位能看出是占位。
