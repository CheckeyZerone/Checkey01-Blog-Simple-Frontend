# T-D2 全局设计系统

**目标**：把蓝稿的「视觉语言」先固化到全局样式，后续页面只引用，不再各写各的。

## 涉及文件

- `src/assets/main.css`（主要）
- `index.html`（字体栈可选）

## 步骤

1. 核对 CSS 变量：`--main-blue: #2080f0`、`--deep-blue: #263473`、`--light-blue: #eaf2ff`、`--red: #d03050`、`--pink: #ff8e9b`、`--yellow: #ffc53d`、正文 `#333639 / #767c82 / #9aa3b2`、页面底 `#efeff5`、描边 `#e3e7f0`（已有则确认一致）
2. 卡片通用样式：白底、`border-radius: 16px`、边框 `var(--border)`、柔和蓝影（设计稿约 `rgb(32 128 240 / 0.14)`）
3. 按钮 `.btn`：胶囊全圆角、主色 `--main-blue`、hover 上浮 2px + 阴影加深、active `scale(0.97)`、ghost 白底蓝字
4. 标签胶囊 `.tag`：`#bfd9fb` 边框、`--light-blue` 底、`--main-blue` 字
5. 分页公共样式（供 T-D3 的 Pagination 组件使用）
6. 字体：system-ui + PingFang SC / Microsoft YaHei 回退；Blueaka 是商业字体，暂不引入
7. 动效统一：`prefers-reduced-motion: reduce` 时关闭位移/缩放

**完成标志**：任意页面挂上公共类即呈现蓝稿质感；`npm run dev` + lint 通过。

**审查重点**：不新建同义变量（沿用 `--main-blue` 等）；样式只进全局一次，页面不复制。

**本任务概念**：CSS 变量、全局样式与作用域样式分工。
