# T-D6 友链页改造

**目标**：LinksView 改成设计稿网格卡片：LOGO 区（渐变圆角方块 + 首字母）、站名、域名、简介、「访问」按钮。

## 涉及文件

- `src/views/LinksView.vue`（主要）
- `src/data/links.ts`（数据结构扩展：加 domain，可选 avatar）
- 可选 `src/components/FriendCard.vue`（与 PostCard 同级，可复用）

## 步骤

1. 数据字段：`name / url / description / domain`；LOGO 区先用站点名首字母（或 `avatar` 图片字段）
2. 布局：三列 → 两列 → 单列（与相册同断点），卡片 16px 圆角、白底、hover 上浮
3. 「访问」按钮：蓝色胶囊 + 箭头，`target="_blank" rel="noopener noreferrer"`
4. 示例数据换为设计稿三条（Kiwi233 的博客 / ZLX STUDIO / 莱卡云），后续替换真实友链
5. 页面标题「友情链接」+ 一句说明（欢迎交换友链）

**完成标志**：`/links` 与设计稿一致，导航可进入，移动端正常。

**审查重点**：外链安全属性；域名溢出；卡片网格对齐。

**本任务概念**：卡片网格、外链安全（noopener noreferrer）。
