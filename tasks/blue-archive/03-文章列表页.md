# T-D3 文章列表页（彻底替换旧标签页）

**目标**：把旧「标签」页改造成设计稿「文章」页：标签筛选条 + 首篇横向大卡 + 其余纵向双列 + 分页。不做两套页面。

## 涉及文件

- 新建 `src/views/PostsView.vue`（页面主体）
- 新建 `src/components/Pagination.vue`（公共分页，T-D8 相册页复用）
- 新建或抽取 `src/components/TagFilterBar.vue`（标签筛选条）
- 修改 `src/router/index.ts`：`/posts` 注册 + 旧 `/tags` 路由处理
- 修改 `src/components/PostCard.vue`：支持 featured 横向大卡模式
- 修改卡片内标签链接（`/posts?tag=xxx` 或旧路径，视决策）

## 步骤

1. 标签数据继续用 `src/data/articles.ts` 汇总（与服务层不冲突）
2. 页面结构：筛选条（全部 / 各标签 + 数量）→ 首篇 featured 大卡 → 其余双列网格 → 分页
3. 分页：`Pagination.vue` 收 `currentPage / totalPages`，发 `page-change`；列表 `slice()` 切页；文章不足一页也显示组件（供以后扩展）
4. 路由决策（见 README 待定项）：推荐删除 TagsView/TagPostsView，`/tags` 与 `/tags/:tag` 重定向到 `/posts` / `/posts?tag=xxx`
5. 旧 T-D5 之前保留旧页面可暂时可访问，本任务完成后旧标签页必须不再是独立页面

**完成标志**：导航「文章」进入新页；点标签筛选正确；分页可翻页；旧标签页不存在或仅为重定向壳。

**审查重点**：无死链（所有进标签的入口指向新页）；无未使用的旧组件文件；筛选与分页组合时页码重置正确。

**本任务概念**：路由 query、分页 slice、组件 props/emits。
