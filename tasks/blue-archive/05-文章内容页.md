# T-D5 文章内容页

**目标**：PostView 按设计稿改造：白底圆角卡片 + 返回链接 + meta + 上一篇 / 下一篇。

## 涉及文件

- `src/views/PostView.vue`（主要）
- 复用 `src/utils/markdown.ts`（不改动渲染管线）

## 步骤

1. 外层白底卡片：`border-radius: 16px`、柔和蓝影、`max-width: 48rem` 居中
2. 顶部「← 返回文章」链接（回 `/posts`，尽量保留来源标签/页码）
3. meta：日期 · 阅读时长（阅读时间算法抽成公共函数，与 PostCard 一致）
4. 标签胶囊
5. 正文排版沿用 `main.css` 的 `.content` 规则；如需对齐设计稿（h2 24px / h3 18px / 16px · 1.8 行高）在全局统一调整
6. 底部「上一篇 / 下一篇」：按日期排序取相邻文章，边界（首篇/末篇）隐藏对应侧，用 `RouterLink` 跳转
7. 「文章不存在」状态保留，样式与卡片一致

**完成标志**：从文章页进入详情，排版、卡片、前后篇导航与设计稿一致。

**审查重点**：阅读时间算法与列表页一致（不复制代码）；上一篇/下一篇边界不报错。

**本任务概念**：路由参数、computed 排序、视觉层级。
