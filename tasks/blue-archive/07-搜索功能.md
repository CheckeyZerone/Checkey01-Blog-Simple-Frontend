# T-D7 搜索功能

**目标**：顶栏搜索框从纯 UI 变为可用功能：本地过滤文章（标题 / 摘要 / 标签）。在 T-D3 ~ T-D5 文章相关完成后做。

## 涉及文件

- `src/components/AppHeader.vue`（输入框行为）
- 数据入口加 `searchArticles(keyword)`（推荐放在数据层，保持解耦）
- `src/views/PostsView.vue`（读取 `route.query.q` 展示搜索结果）

## 步骤

1. 数据入口加 `searchArticles(keyword)`：大小写无关，匹配 title / excerpt / tags
2. Header 搜索框：Enter 提交 → 跳转 `/posts?q=关键词`；空关键字不跳转
3. PostsView 处理 `route.query.q`：显示「搜索结果」，结果为空显示提示
4. 搜索与标签筛选关系（叠加或互斥）二选一并在页面说明

**完成标志**：输入关键词回车后看到过滤结果；清空搜索回到全部文章。

**审查重点**：query 变化时页面自动更新（watch 而非只在 mounted 读一次）；中文匹配正常。

**本任务概念**：表单提交、路由 query、watch。
