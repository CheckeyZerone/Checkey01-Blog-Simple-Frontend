# T-D9 图片内容页

**目标**：实现相册内单张图片页面：信息卡 + 16:9 大图舞台 + 按钮控制横向滚动的缩略条。

## 涉及文件

- 新建 `src/views/PhotoView.vue`
- 路由 `/albums/:albumSlug/photos/:photoId`（带相册上下文，推荐）

## 步骤

1. 路由 + 数据查找：由 albumSlug + photoId 找到照片；找不到显示「图片不存在」
2. 信息卡（图片上方）：「返回相册」→ 标题 → 标签胶囊 → 日期 → 说明
3. 大图舞台：16:9 圆角容器，大图居中，左右圆形箭头切换上一张/下一张（到端禁用或循环，二选一）
4. 缩略条：横向滚动容器（隐藏滚动条），按钮 `scrollBy({ left: 220, behavior: 'smooth' })`，滚到两端按钮禁用
5. 当前图片缩略图蓝色圆环高亮
6. 移动端可触摸滑动；大图高度自适应

**完成标志**：从相册点图进入，箭头可切换、缩略条可滚动、选中态正确；无评论区。

**审查重点**：scrollBy/scrollLeft 边界禁用计算正确；切换图片后缩略条自动滚到当前项可见。

**本任务概念**：动态路由嵌套、scrollBy 横向滚动、DOM 滚动边界。
